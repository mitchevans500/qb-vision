# QB Vision

A small flag football practice game: read the defense before the snap, then make the throw.

One page, no accounts, no tracking, no network requests after it is installed. Progress is kept only on the device.

Play: open the page, then use Share > Add to Home Screen. Open the new icon once while online; after that it plays with no connection.

Build 2026.11.22-11c253. Fonts: Graduate and Lexend (SIL Open Font License 1.1).
